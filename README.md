# Privacy-Filtering-in-3D-Map-Reconstruction
This is research project for a 10-week Summer Undergraduate Research Fellowship (SURF) at FAU. This project will tackle privacy in robotics where I will be exploring how to exclude private objects or events from a 3D map reconstruction to ensure privacy.

## Project Overview:
In this project, we will explore how to exclude private objects or events from the 3D map reconstruction. The objectives of this project are to take text instructions as input, process them through an LLM to identify what should be considered private, and explore how to exclude the prompted private objects from a 3D reconstruction map output. There are several methods to explore, including whether filtering private objects should be conducted during or after map reconstruction, and which method of reconstruction is best suited for the filtering.
